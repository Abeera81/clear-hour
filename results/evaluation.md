# Clear Hour — dataset + TabPFN evaluation

Task: correct the CAMS forecast to predict hourly PM2.5 at OpenAQ sensor 4554236 (Rawalpindi Women University, AirGradient **uncalibrated low-cost sensor**, 5.2 km from the CAMS point; CC BY 4.0, attribution: The Urban Unit), then rank the hours of each day. Generated by `eval/evaluate.py` from `data/processed/hourly.parquet` (built by `src/dataset.py`).

## Dataset

- One row per local hour (Asia/Karachi) with a valid monitor reading; `time` = hour start, y = monitor hourly mean.
- Rows: **11669**. CAMS artifact days 2022-12-14/15 excluded (outside sensor span anyway).
- Features (26, all forecast-available; no monitor reading is a feature): `cams_pm2_5`, `cams_pm10`, `cams_carbon_monoxide`, `cams_nitrogen_dioxide`, `cams_ozone`, `cams_sulphur_dioxide`, `cams_pm2_5_m3h`, `cams_pm2_5_m1h`, `cams_pm2_5_p1h`, `cams_pm2_5_p3h`, `cams_pm2_5_roll24`, `cams_pm2_5_dayrank`, `wx_temperature_2m`, `wx_relative_humidity_2m`, `wx_wind_speed_10m`, `wx_pressure_msl`, `wx_precipitation`, `wx_boundary_layer_height`, `wx_wind_dir_sin`, `wx_wind_dir_cos`, `hour`, `dow`, `month`, `doy_sin`, `doy_cos`, `is_weekend`

## Split (strictly temporal, no shuffling)

| Split | First hour | Last hour | Days | Rows |
|---|---|---|---|---|
| TRAIN | 2025-05-29 11:00:00 | 2026-08-10 23:00:00 | 439 | 10234 |
| DEV | 2026-08-11 00:00:00 | 2026-09-09 23:00:00 | 30 | 716 |
| TEST | 2026-09-10 00:00:00 | 2026-10-09 22:00:00 | 30 | 719 |

- TabPFN training rows for DEV: **10000** (TRAIN exceeds 10000: subsampled to the most recent 10000 rows, 2025-06-09 09:00:00 → 2026-08-10 23:00:00)
- TabPFN: `tabpfn-v2-regressor.ckpt`, TabPFNRegressor v2, fit_mode=fit_with_cache, CPU, `ignore_pretraining_limits=True` (required by tabpfn for >1,000 rows on CPU), no tuning; fit+predict 3324.3 s.
- Pre-registered before TEST: for TEST, every model is refit on TRAIN+DEV (TabPFN: most recent 10,000 rows of that) and scored once on TEST.

Metric definitions: Bias = mean(pred − actual). Within-day ρ = Spearman(pred, actual) per day with ≥20 hours. Top-2h-window hit = model's lowest-predicted 2 consecutive hours both fall in the day's 6 lowest actual hours. Window columns = mean actual PM2.5 (µg/m³) of the model's chosen window / the best possible 2-h window / the day mean, averaged over days.

## Validity check — sensor 4554236 vs US Embassy reference monitor

- Overlap: **5385 h** (2025-05-29 → 2026-02-16), ~15 km apart
- Hourly Pearson r **0.809**; daily-mean r **0.951**
- Mean difference (sensor − embassy) **+14.7 µg/m³**; MAE **25.0**; means 75.8 (sensor) vs 61.1 (embassy); median ratio sensor/embassy 1.21

The low-cost sensor tracks the reference monitor's day-to-day changes well (daily r 0.95, hourly r 0.81) but differs in level (mean difference +14.7 µg/m³) and is 15 km away in a different part of the city, so hourly disagreement mixes sensor error with real spatial differences. We therefore treat its absolute values as indicative only and lean on the ranking metrics (which ignore level offsets) as the product metric.

## Limitations

- **Ground truth is an uncalibrated low-cost sensor** (AirGradient, OpenAQ 4554236). Absolute µg/m³ errors are relative to this sensor, not to a reference monitor; see the validity check.
- **CAMS and weather inputs are archive values, not true day-ahead forecasts.** The Open-Meteo CAMS archive is stitched from the most recent model runs, and the weather archive is reanalysis/best-match. A real day-ahead run uses older forecasts (lead 24–48 h), so live skill will likely be worse than shown here for all CAMS-based models alike.
- **Short history**: the sensor starts 2025-05-29, so TRAIN contains exactly one Oct–Dec smog season (2025). B3's season cells and any seasonal learning rest on that single season.
- **DEV/TEST are 30 days each** (late Aug → early Oct 2026), i.e. the transition into smog season; they say little about mid-winter performance. Bootstrap CIs are by day and so reflect only ~30 independent days.
- **TabPFN context limit**: TabPFN sees at most the most recent 10,000 training rows; older rows are dropped for it (not for the other models).
- **Single location, single sensor**: one AirGradient unit can drift, be moved, or be locally affected; no cross-sensor consistency check is done here.
- CAMS alignment (instantaneous value at hour start vs the monitor's hourly mean) is a fixed convention; ±1 h CAMS shifts are provided as features so learned models can adjust, the bias baselines cannot.
